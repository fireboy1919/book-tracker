📧 BookTracker Parent Invitation Email Templates

🚀 How to Use These Templates

These email templates work with the Google Sheets invitation system. You can:

  • Copy and paste the templates below and manually replace the merge fields
  • Use Gmail Mail Merge or similar tools to automatically fill in student names and URLs
  • Customize the templates to match your teaching style and school requirements

Merge Fields Available:

  • {{STUDENT_NAME}} - Student's full name from Column A
  • {{INVITATION_URL}} - Complete invitation URL from Column D
  • {{TEACHER_NAME}} - Your name (customize in template)
  • {{CLASS_NAME}} - Your class name (customize in template)
  • {{SCHOOL_NAME}} - Your school name (customize in template)

⚠️ Important Security Reminders

  • Never share invitation links between families - each link is unique
  • Links expire in 30 days - remind parents to register promptly
  • Class ID security - tokens only work for your specific class
  • One account per family - parents should register once per invitation link

📋 Mail Merge Setup Instructions

Using Gmail Mail Merge:

  1. Export your Google Sheet to CSV (File → Download → CSV)
  2. Install a Gmail Mail Merge add-on (like "Yet Another Mail Merge")
  3. Create a new Gmail draft with the merge template
  4. Upload your CSV and map the columns:
    • Column A (Student Name) → <>
    • Column B (Parent Email) → Email Address
    • Column D (Invitation URL) → <>
  5. Send test emails first, then send to all

Using Mailchimp or Similar:

  1. Upload your CSV to your email platform
  2. Create a new email campaign
  3. Use the merge template above
  4. Map merge fields to your CSV columns
  5. Test with a small group first

Manual Copy-Paste Method:

  1. Copy a template above
  2. Replace {{STUDENT_NAME}} with the actual student name
  3. Replace {{INVITATION_URL}} with the URL from Column D
  4. Send individual emails
